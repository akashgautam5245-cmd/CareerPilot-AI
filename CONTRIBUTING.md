# Contributing to SolveFlow AI 🚀

Thank you for your interest in contributing to **SolveFlow AI – Smart Daily Work & Problem Management System**!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/solveflow-ai.git
   cd solveflow-ai
   ```
3. **Create a feature branch**:
   ```bash
   git checkout -b feature/amazing-new-feature
   ```
4. **Install dependencies and test**:
   - Backend: `cd server && npm install && npm test`
   - Frontend: `cd client && npm install`
   - AI Service: `cd ai-service && pip install -r requirements.txt`
5. **Commit your changes**:
   ```bash
   git commit -m "feat: add amazing new feature"
   ```
6. **Push to GitHub** and open a **Pull Request**.

## Guidelines

- Follow existing TypeScript and Python coding conventions.
- Maintain dark/light mode SaaS aesthetics.
- Ensure all API endpoints handle errors gracefully.
